# Collapsed section（折り畳みセクション）

長いサンプルコードやログ、行数の多い箇条書きやテーブルにのみ使う。本文をすっきりさせたいという理由だけで多用しない。短い補足、通常の説明、標準手順、実行前に必要な条件や警告は折り畳まない。

`<summary>` には、中身が分かる見出しを書く。折り畳みの中には見出し・テキスト・コードブロック・画像などを含められるが、折り畳む対象自体は上記の用途に限定する。

以下は、長いサンプルコードを格納する場合の記法例。コード本体は例示のため省略している。

````markdown
<details>

<summary>設定スクリプトの全文</summary>

### 設定スクリプト

```bash
# 長いサンプルコードの全文をここに記載する
```

</details>
````

`<details>` と `<summary>...</summary>` の後には空行を置き、中のMarkdownが解釈されるようにする。外側のコードフェンスは、中のコードフェンスより長くする。
