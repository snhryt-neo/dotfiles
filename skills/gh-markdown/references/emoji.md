# Emoji shortcode（絵文字）

`:emoji_name:` で絵文字を埋め込める。既存の文書の作法やユーザーの指定に合う場合に使う。

```markdown
## 🚀 Getting Started   <!-- Unicode絵文字でもOK -->
## :rocket: Getting Started  <!-- shortcodeでもOK -->
```

よく使うもの: `:warning:` ⚠️  `:information_source:` ℹ️  `:white_check_mark:` ✅  `:x:` ❌  `:bulb:` 💡  `:memo:` 📝  `:rocket:` 🚀  `:construction:` 🚧
